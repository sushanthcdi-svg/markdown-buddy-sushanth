## Reflection 1: How did AI help with creating project documentation?

ChatGPT helped me understand the essential sections of a professional GitHub README, including Overview, Installation, Requirements, Project Structure, Example Usage, Outputs, License, and AI Assistance Disclosure.

I began by asking ChatGPT to explain what sections a good README for an R data analysis project should include. I then used refinement prompts to make the content more concise and improve the Markdown formatting.

AI also assisted with organizing the R Markdown documentation into clear sections describing the script's purpose, inputs, outputs, and code examples.

This process showed me how AI can improve the efficiency and consistency of technical documentation while still requiring human review.

## Reflection 2: What challenges did you encounter, and how did you validate the AI-generated documentation?

One important challenge was understanding how Markdown syntax works and ensuring that headings, bullet points, and code blocks were formatted correctly.

I addressed this by reviewing GitHub's Markdown documentation and using ChatGPT to examine the structure and readability of the README.

I also compared the README structure with the tidyverse/dplyr GitHub repository to understand how professional R projects organize documentation.

For the R Markdown file, I used Posit Cloud to knit `Script_Documentation.Rmd` into HTML. This helped verify that the document could be rendered successfully.

These checks helped me understand why AI-generated content should be independently tested rather than accepted without review.

## Reflection 3: What did you learn about responsible AI use in technical documentation?

I learned that AI is a useful assistant for generating outlines, suggesting improvements, and explaining Markdown formatting.

However, AI-generated documentation may contain errors, missing information, or code that has not been tested.

Therefore, it is important to review the content, verify technical instructions, check code execution, and confirm that the documentation accurately represents the project.

I also learned the importance of disclosing AI use by recording the tool name, version, date, prompts, and key responses.

In future projects, I would use AI to support drafting and editing while independently verifying the final documentation to maintain accuracy, transparency, and academic integrity.
